# Rotaract Club of Bharatpur — Official Website
Fellowship Through Service. Built with Astro, TypeScript and Tailwind CSS 4.

## Develop
Requires Node.js 22.23.4 or newer.
npm install && npm run dev

## Build
npm run build (output in dist/)

## Edit content
src/data/site.ts, leadership.ts, activities.ts

## Deploy
Cloudflare Pages: build command `npm run build`, output directory `dist`.
